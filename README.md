# TestScore – Конзолно приложение (C#)
## Описание

Това е просто конзолно приложение на C#, което въвежда име и резултат от тест, изчислява оценка и извежда информацията на екрана.

## Функционалност

- Въвеждане на име на студент

- Въвеждане на резултат (score)

- Изчисляване на оценка чрез GradeCalculation.CalculateGrade

- Съхраняване на данните в клас TestScore

- Извеждане на име, резултат и оценка

## Структура

- Program.cs – входна точка на приложението

- TestScore.cs – клас за съхранение и отпечатване на данните
